# Segundo Examen Parcial - Machine Learning

Este repositorio contiene la solución modular al segundo parcial del curso de Machine Learning. El proyecto evalúa la complejidad de los modelos, la generalización y la sensibilidad a la muestra utilizando regresión polinomial.

## Instalación y Reproducción

1. Clone el repositorio a VS

2. Crear un entorno virtual e instalar las dependencias:
    ```bash
    python -m venv venv
    venv\Scripts\activate  
    pip install -r requirements.txt
    pip install -e .
    ```

3. Abrir y ejecutar el cuaderno en notebooks/parcial.ipynb desde un kernel reiniciado para reproducir todos los resultados y figuras.
